# Project databases (project_db): DuckDB and its spatial extension, pinned
# by version and by the SHA-256 of each wheel. Install on its own, so every
# wheel is checked and nothing else is pulled in:
#
#   python -m pip install --require-hashes --no-deps --only-binary :all: -r workers/python/requirements-projectdb.txt
#
# Wheels: CPython 3.12 and 3.13 on Windows x64, macOS arm64 and Linux x64.
#
# duckdb-extension-spatial is a community package (not DuckDB Labs') that
# carries DuckDB Labs' own signed spatial.duckdb_extension for this exact
# DuckDB version. Columbus never imports the package (its __init__.py never
# runs): the worker finds the file with importlib.util.find_spec, and DuckDB
# checks the binary's signature when it loads it (unsigned extensions are
# refused). The extension is never downloaded at run time. Without it,
# project databases still work; only the spatial SQL functions are missing.
# To move to a new DuckDB version, change both versions and every hash
# (from https://pypi.org/project/duckdb/#files and
# https://pypi.org/project/duckdb-extension-spatial/#files).
