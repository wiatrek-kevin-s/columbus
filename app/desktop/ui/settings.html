    Tools

    Tools your assistant made from scripts, so it (and any assistant you use with Columbus) can reuse them. You read each one and install it here; it then runs whenever it is needed, without asking, in the same sandbox as scripts: no network, only the layers it is given, writing only its own results. Ask your assistant, for example: add the script we just made as a tool.

    Personal tools are turned off in your organization's settings, so none of these are used, and none can be installed.
